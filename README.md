# Malvina Living · Lotes en Caucasia

App (PWA) de **Vibras Positivas HM** para que Harold Marín venda lotes del proyecto Malvina Living (Inversiones Camino Verde S.A.S.), con su **código de referido HAROLD-HM**.

## Qué trae
- Portada con la vista aérea del proyecto, precio total $39.600.000, 12 cuotas sin interés y separación con $2.000.000.
- El lote de 6 x 12 m (72 m²), valor m² $550.000, inicial del 35 % y lotes de esquina/orilla de carretera (+$10.000.000).
- Tabla de cuotas 12 / 18 / 24 / 36 y **simulador** (1,5 % mensual) para lote estándar o de esquina.
- Todo llega al WhatsApp de Inversiones Camino Verde (302 105 2219) con "Vengo referido por el asesor Harold Marín · Código HAROLD-HM".
- Volante oficial para descargar y compartir. Botón Compartir con `?ref=HAROLD-HM`.
- Español e inglés, hora de Colombia, Habeas Data, instalable.

## Código de referido
Todos los mensajes de WhatsApp terminan con "Vengo referido por el asesor Harold Marín (311 770 0431) / Código de referido: HAROLD-HM".
Otro vendedor puede usar su propio enlace: `.../?ref=ANA-77`.

const WHATSAPP = "573021052219"; // Inversiones Camino Verde S.A.S.
const REF_DEFECTO = "HAROLD-HM";
const PRECIO_BASE = 39600000;
